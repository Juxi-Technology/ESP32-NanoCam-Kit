# 第18章: 小车与云台控制

> 难度: ★★★ | 产出: 智能小车 / AI 视觉追踪小车

## 两种方案对比

NanoCam 控制小车有两种架构，选用前先确认你的需求：

| 项目 | 方案 A: WiFi 串口透传遥控 | 方案 B: I2C AI 视觉追踪 |
|------|--------------------------|------------------------|
| 原理 | 手机 App → WiFi → NanoCam → 串口 → 主控 MCU → 电机/舵机 | NanoCam AI 检测 → I2C 输出坐标 → 主控 MCU 读取 → 舵机跟踪 |
| NanoCam 角色 | WiFi 桥接 (透传) | AI 视觉处理器 |
| AI 模式 | 无 (纯图传/透传) | mode 1-5 (猫脸/人脸/颜色/人脸识别/QR) |
| 通信协议 | 串口 AT 指令 (`ai_mode:2` 等) | I2C 从机 (地址 0x33, 寄存器 0x28-0x2B) |
| 例程覆盖 | ✅ 全部已实现 | ⚠️ 核心逻辑需用户自行编写 |
| 适用场景 | 手机遥控小车 | 自动追踪人脸/颜色/物体 |

## 方案 A: WiFi 串口透传遥控 (已实现)

手机通过 WiFi 连接 NanoCam，App 发送控制指令 (`$1,0,0,0#` 前进等)，NanoCam 通过串口转发给主控 MCU。

### 例程

| 例程 | 路径 | 平台 | 功能 |
|------|------|------|------|
| `ESP_4wdCar_no_servo.ino` | `libraries/Examples/Car_Control/Arduino_4WD/` | Arduino UNO | 4WD 小车 + NanoCam WiFi 遥控 |
| `ESP_4wdCar_with_servo.ino` | `libraries/Examples/Car_Control/Arduino_4WD/` | Arduino UNO | 4WD 小车 + 舵机云台 WiFi 遥控 |
| `esp32_pico_car_servo.py` | `libraries/Examples/Car_Control/Pico_Car/` | Raspberry Pi Pico | 小车 + 云台 (MicroPython) |
| `microbit-wifi_supkit.hex` | `libraries/Microbit/` | Micro:bit | 舵机云台控制 |

> 以上例程均使用**串口 AT 协议**（见 [串口协议手册](../串口协议手册.md)），NanoCam 工作在 WiFi 透传模式。

## 方案 B: I2C AI 视觉追踪 (框架)

NanoCam 运行 AI 检测，通过 I2C 从机 (地址 `0x33`) 输出检测框坐标，外部 MCU 读取后控制舵机云台跟踪目标。

### 实战: AI 人脸追踪小车

1. 通过串口发送 `ai_mode:2` 使 NanoCam 进入人脸检测模式
2. 外部 MCU 通过 I2C 读取人脸中心坐标 (寄存器 `0x28`-`0x2B`，详见 [I2C协议手册](../I2C协议手册.md))
3. X 轴偏差 → 舵机云台左右转
4. 人脸面积变化 → 小车前进/后退

### I2C 读取示例 (Arduino)

```cpp
#include <Wire.h>

// NanoCam I2C：SDA=GPIO41, SCL=GPIO42 (地址 0x33)
// 主控端 (Arduino) 只需按自己的 I2C 引脚连接即可

void readFaceCenter(int *mx, int *my) {
    Wire.beginTransmission(0x33);
    Wire.write(0x28);              // 中心点 X 寄存器
    Wire.endTransmission(false);
    Wire.requestFrom(0x33, 4);     // 读 4 字节 (MX+MY)
    if (Wire.available() == 4) {
        *mx = (Wire.read() << 8) | Wire.read();
        *my = (Wire.read() << 8) | Wire.read();
    }
}

void trackServo(int mx) {
    // QVGA 中心 = 160，偏差驱动舵机
    int dx = mx - 160;
    int angle = constrain(90 + dx / 5, 0, 180);

}
```

> ⚠️ 注意：以上 I2C 追踪代码仅示范核心逻辑，完整项目需结合 [NanoCam Arduino 库](../../libraries/Arduino/NanoCam.h) (`libraries/Arduino/`) 的 `readDetection()` 方法，或参考 `libraries/Arduino/examples/FaceTracking/` 的串口版本改写为 I2C 版本。
