# 第17章: 树莓派控制 NanoCam

> 难度: ★★☆ | 产出: 树莓派 AI 视觉系统 + LLM 服务器

## 原理

树莓派通过 UART 或 I2C 连接 NanoCam,可使用 Python 库控制,也可以自部署 LLM 服务器实现模式B。

## 内容

### 17.1 UART 连接
```bash
sudo raspi-config  # 启用 Serial Port
pip install nanocam
```
```python
from nanocam import NanoCam
cam = NanoCam("/dev/ttyS0")
```

### 17.2 自部署 xiaozhi-server
```bash
git clone https://github.com/xinnan-tech/xiaozhi-esp32-server
cd xiaozhi-esp32-server
pip install -r requirements.txt
python app.py
```

### 17.3 ROS2 + micro-ROS
```bash
docker run -it --rm --net=host microros/micro-ros-agent:humble udp4 --port 9999
```
