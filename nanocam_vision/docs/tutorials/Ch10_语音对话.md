# 第10章: 语音对话

> 难度: ★★★ | 模式: ai_mode:6 | 产出: AI桌面伴侣

## 原理

NanoCam 集成小智AI框架,通过 WebSocket 连接 LLM 服务器实现:
麦克风采集→Opus编码→WebSocket→ASR语音识别→LLM大模型生成回复→TTS语音合成→Opus解码→扬声器播放

## 配置

XiaoZhi AI 默认连接官方免费服务器 [xiaozhi.me](https://xiaozhi.me)。

### 使用步骤

| # | 步骤 | 说明 |
|:--:|------|------|
| 1 | 注册 [xiaozhi.me](https://xiaozhi.me) | 免费账号 |
| 2 | 设备上电 → `ai_mode:6` | 进入 XiaoZhi AI 模式 |
| 3 | 设备显示激活码 | 串口或屏幕显示 6 位数字 |
| 4 | 在 xiaozhi.me 控制台输入激活码 | 绑定设备到账号 |
| 5 | 选择模型 (Qwen/DeepSeek 等) | 控制台配置 |
| 6 | 说"你好小智" → 开始对话 | 🎉 |

### 自部署服务器（可选，可跳过）

如需本地运行（隐私/离线/自定义），可自行部署：

```
nano_server:http://192.168.1.100:8000
```
```bash
git clone https://github.com/xinnan-tech/xiaozhi-esp32-server
cd xiaozhi-esp32-server && pip install -r requirements.txt
python app.py
```

## 步骤

### 10.1 切换 LLM 模式
```
ai_mode:6
```

设备自动重启，WS2812 LED 显示白色。

### 10.2 语音唤醒
说"你好小智",听到应答音。

### 10.3 自由对话
"今天天气怎么样"→AI 语音回答。
"讲个笑话"→AI 语音回答。
