# 第8章: 人脸识别

> 难度: ★★★ | 模式: ai_mode:4 | 产出: 人脸门禁系统

## 原理

人脸识别 = 人脸检测(ESP-DL) + 特征提取(ESP-WHO) + 特征比对。先注册多个人脸,提取特征向量存储。辨认时提取当前人脸特征与已注册特征对比,返回最相似的 ID。

## 步骤

### 8.1 进入识别模式
```
ai_mode:4
```

### 8.2 注册人脸
`KEY_MENU` → 对准人脸 → 保存特征。重复注册 3 个人。

### 8.3 辨认人脸
`KEY_PLAY` → 当前人脸与已注册特征比对 → 显示 "User 1" 或 "Unknown"。

### 8.4 删除人脸
`KEY_DOWN` → 删除最后一个注册的人脸。

## 代码

### Arduino 人脸门禁
```cpp
// I2C 读取人脸 ID (寄存器 0x2C-0x2D)
Wire.beginTransmission(0x33);
Wire.write(0x2C);
Wire.endTransmission(false);
Wire.requestFrom(0x33, 2);
int faceId = (Wire.read()<<8) | Wire.read();
if (faceId > 0) {
    digitalWrite(RELAY_PIN, HIGH);  // 开门
    delay(3000);
    digitalWrite(RELAY_PIN, LOW);
}
```

## 效果
张三刷脸→辨认成功→IO输出→继电器开门。
