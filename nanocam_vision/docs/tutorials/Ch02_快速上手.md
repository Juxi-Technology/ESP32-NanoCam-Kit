# 第2章: 快速上手

> 时间: 10分钟 | 目标: 烧录固件→配网→看到实时画面

---

## 2.1 固件烧录

> 产出: **一个烧录好固件的 NanoCam**

### 步骤

1. 下载最新固件: [GitHub Releases](https://github.com/Juxi-Technology/ESP32-NanoCam/releases) → `nanocam_vX.X.X.bin`
2. 打开 [esptool-js](https://espressif.github.io/esptool-js/)
3. Type-C 连接 NanoCam
4. 点击 Connect → 选择串口
5. 选择固件文件, 地址填 `0x0`
6. 点击 Program → 等待完成

### 验证

串口工具(115200 8N1)连接 NanoCam, 应看到:
```
NanoCam Board Ver:0.2.0
```

---

## 2.2 WiFi 配网

> 产出: **NanoCam 连上 WiFi, 获得 IP**

### 方式A: 串口配网(最常用)

```
sta_ssid:你的WiFi名
sta_pd:你的WiFi密码
```

收到 `OK` → 设置成功。密码修改后自动重启。

### 方式B: AP 热点直连

NanoCam 自带热点: `NanoCam-AP`, 密码 `12345678`
手机连上后,浏览器打开 `http://192.168.4.1`

### 方式C: Web 管理后台

浏览器打开 `http://192.168.4.1/admin`

### 验证

```
sta_ip
```
返回: `sta_ip:192.168.x.x` ✅

---

## 2.3 第一帧画面

> 产出: **浏览器看到 NanoCam 实时画面**

1. 浏览器输入 `http://<IP地址>`
2. 看到实时 MJPEG 画面 🎉
3. 串口发 `ai_mode:1` → 切换到猫脸检测 → 画面出现检测框

### 端点说明

| URL | 用途 |
|-----|------|
| `http://<IP>/` | 实时画面(HTML) |
| `http://<IP>/stream` | 纯 MJPEG 流(OpenCV/VLC可读) |
| `http://<IP>/status` | 设备状态 JSON |
| `http://<IP>/admin` | Web 管理后台 |
