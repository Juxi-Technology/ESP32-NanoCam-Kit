# 第5章: 猫脸检测

> 难度: ★★☆ | 模式: ai_mode:1 | 产出: 宠物监测系统

## 原理

猫脸检测使用 CatFaceDetectMN03 模型,专为猫脸部特征(耳部/眼部/鼻部)优化训练。与通用人脸检测不同,它针对猫的面部几何结构进行了专门适配。

### 猫脸 vs 人脸模型差异
- 猫脸: 三角耳部特征, 较宽的瞳距
- 人脸: 椭圆形轮廓, 五官比例规则

## 步骤

### 5.1 切换模式
```
ai_mode:1
```

### 5.2 查看置信度
串口输出格式含置信度分数(0-1),>0.8 为可靠检测。

### 5.3 MQTT 推送
```
nano_mqtt:192.168.1.100,1883,cat/detect
```
检测到猫咪时推送 JSON: `{"type":"cat","confidence":0.92}`

## 代码

### MQTT 订阅端 (Python)
```python
import paho.mqtt.client as mqtt
def on_message(client, userdata, msg):
    data = json.loads(msg.payload)
    if data.get("type") == "cat":
        print(f"Cat detected! Confidence: {data.get('confidence')}")
```

## 效果
猫咪出现→画面标注猫脸框→MQTT推送→手机收到通知。
