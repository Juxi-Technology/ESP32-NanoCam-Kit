# 第9章: 运动检测

> 难度: ★★☆ | 模式: 未来版本 | 产出: 智能安防报警

## 原理

帧差法: 比较连续两帧图像的像素差异。当差异超过灵敏度阈值时,判定画面中有物体运动。

### 关键参数
- 灵敏度: 像素差异阈值,值越低越敏感
- 检测区域: 可配置 ROI(感兴趣区域),忽略无关区域

### 9.3 GPIO 触发
运动检测→IO 口输出高低电平→触发外部报警器。
