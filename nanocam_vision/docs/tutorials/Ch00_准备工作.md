## 0.1 产品介绍

**NanoCam** 是多Agent AI相机 —— 同一块硬件,三种AI能力:

| 模式 | 类型 | 功能 | 是否联网 |
|------|------|------|:--:|
| **A: 边缘视觉** | 7种离线AI | 猫脸/人脸/颜色/QR/运动检测 | 不需要 |
| **B: LLM Agent** | XiaoZhi AI | 语音对话 + AI视觉理解 + 设备控制 | 需要 |
| **C: ESP-Claw** | 乐鑫官方 | IM聊天造物 + Lua动态加载 + MCP | 需要 |

### 硬件组成

- **核心板**: ESP32-S3 N16R8 (16MB Flash + 8MB PSRAM)
- **摄像头**: GC2145 (200万像素,DVP接口,出厂默认)
- **麦克风**: AP2718AT 模拟 MEMS 麦 → ES8311 Codec
- **音频 Codec**: ES8311 (I2S + I2C)
- **扬声器**: NS4150B 模拟功放
- **底板**: USB-C 供电 + CH340K 串口烧录

### 适用场景

| 场景 | 使用模式 |
|------|---------|
| AI视觉检测 | 模式A — 猫脸/人脸/颜色/QR |
| 机器人视觉 | 模式A — 串口/I2C输出坐标 |
| AI语音助手 | 模式B — 语音对话 |
| 智能安防 | 模式A+B — 运动检测+报警 |
| 物联网AI节点 | 模式A+B — MQTT推送 |

## 0.2 开箱检查

### 硬件清单

- [ ] NanoCam 核心板 ×1
- [ ] NanoCam 底板 ×1
- [ ] GC2145 摄像头模组 ×1 (出厂已连接)
- [ ] FPC 排线 (已连接)
- [ ] Type-C 数据线 (需自备)

### 接口说明

```
核心板正面:
  ┌──────────────────────┐
  │  [摄像头FPC接口]      │ ← 24Pin FPC排座
  │                      │
  │  ESP32-S3            │
  │  ES8311 Codec        │
  │  AP2718AT 麦克风       │
  └──────────────────────┘
          ││  排针插到底板
  ┌───────┘└──────────────┐
  │  底板                 │
  │  USB-C ← 供电+烧录    │
  │  CH340K 串口芯片      │
  │  I2C/UART 扩展口      │
  └───────────────────────┘
```

### 上电自检

1. 核心板插到底板上
2. Type-C 线连接电脑
3. 底板电源 LED 亮起 = 正常

### 常见问题

| 问题 | 解决 |
|------|------|
| LED不亮 | 检查Type-C线是否支持供电 |
| 摄像头无反应 | FPC排线金属触点朝下插紧 |
| 串口不识别 | 安装 [CH340K驱动](https://www.wch.cn/download/CH341SER_EXE.html) |
