# 第7章: 二维码扫描

> 难度: ★☆☆ | 模式: ai_mode:5 | 产出: 快递扫码枪

## 原理

使用 esp-code-scanner 库实时解码画面中的二维码/条形码。解码成功后通过串口以 `$data#` 格式透传。

## 步骤

### 7.1 切换模式
```
ai_mode:5
```

### 7.2 扫描
将二维码放在摄像头前,串口输出: `$https://example.com#`

### 7.3 连续扫码
对准下一个码自动解码输出。

## 代码

### Arduino 扫码记录
```cpp
if (nanoSerial.available()) {
    String line = nanoSerial.readStringUntil('
');
    if (line.startsWith("$") && line.endsWith("#")) {
        String data = line.substring(1, line.length()-1);
        Serial.println("Scanned: " + data);
        // 写入 SD 卡或发送到服务器
    }
}
```

## 效果
对准二维码→串口实时输出解码内容。
