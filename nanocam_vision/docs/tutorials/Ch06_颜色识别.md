# 第6章: 颜色识别

> 难度: ★★★ | 模式: ai_mode:3 | 产出: 颜色分拣机

## 原理

颜色识别基于 HSV(色调-饱和度-明度)色彩空间。先框选目标区域提取 HSV 范围,然后在全图搜索匹配像素。比 RGB 更适合光照变化场景。

## 步骤

### 6.1 进入颜色模式
```
ai_mode:3
```

### 6.2 录入颜色
| 指令 | 功能 |
|------|------|
| `KEY_MENU` | 录入/检测切换 |
| `KEY_PLAY` | 确定录入/删除颜色 |
| `KEY_UPUP` / `KEY_DOWN` | 调整框大小 |

### 6.3 多颜色检测
可录入多种颜色,同时追踪。

### 6.4 获取坐标
I2C 寄存器 0x28-0x2B 读取中心点坐标。

## 代码

### Arduino 颜色分拣
```cpp
// I2C 读取颜色中心坐标
Wire.beginTransmission(0x33);
Wire.write(0x28);
Wire.endTransmission(false);
Wire.requestFrom(0x33, 4);
int mx = (Wire.read()<<8) | Wire.read();
int my = (Wire.read()<<8) | Wire.read();
// 根据 X 坐标触发不同舵机
if (mx < 100) sortLeft(); else sortRight();
```

## 效果
红绿蓝小球→识别颜色→坐标输出→舵机分拣。
