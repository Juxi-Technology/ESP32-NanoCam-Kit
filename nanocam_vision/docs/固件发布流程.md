# NanoCam 固件发布流程

## 发布前检查清单

- [ ] `idf.py build` 编译通过, 无 warning
- [ ] 所有 AI 模式在硬件上验证通过
- [ ] `idf.py size` 检查固件 < 3MB (factory分区限制)
- [ ] 串口 AT 指令全部可用
- [ ] HTTP `/` `/stream` `/status` `/api` 端点正常
- [ ] WiFi AP+STA 双模正常
- [ ] CHANGELOG.md 更新
- [ ] 版本号在 `app_main.cpp` 中更新

## 发布步骤

```bash
# 1. 打 tag
git tag -a vX.Y.Z -m "Release vX.Y.Z"
git push origin vX.Y.Z

# 2. 编译固件
idf.py build

# 3. 复制固件
cp build/nanocam.bin releases/nanocam_vX.Y.Z.bin

# 4. 创建 GitHub Release
# 上传 nanocam_vX.Y.Z.bin
# 填写 Release Notes (参考 CHANGELOG.md)
```
