## 第二部分：快速上手（10分钟到第一帧画面）

### 2.1 固件烧录

> 产出：**一个烧录好固件的 NanoCam**

- 下载最新固件 `.bin` 文件
- 连接 Type-C 到电脑
- 使用网页烧录工具 / esptool 烧录
- 验证：串口输出 `NANOCAM Board Ver:x.x.x`

### 2.2 WiFi 配网

> 产出：**NanoCam 连上 WiFi，获得 IP 地址**

- 方式A：串口助手发 `sta_ssid:xxx` + `sta_pd:xxx`
- 方式B：手机连 NanoCam AP 热点 → 浏览器配网
- 方式C：Web 管理后台配网
- 验证：`sta_ip` → 返回局域网 IP

### 2.3 第一帧画面

> 产出：**浏览器看到 NanoCam 实时画面**

- 浏览器输入 `http://<IP>` → MJPEG 视频流
- 串口发 `ai_mode:1` → 切猫脸模式 → 画面出现检测框
- 完成！你已经会用 NanoCam 了
