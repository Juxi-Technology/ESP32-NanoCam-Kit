## 二、USB-C 电源输入电路

### 2.1 USB-C 接口规格

| 参数 | 值 |
|------|-----|
| 连接器型号 | USB Type-C 母座 16Pin |
| 引脚定义 | USB 2.0 标准 (仅用于供电和 USB 转串口) |
| 输入电压 | 5V |
| 最大输入电流 | ≥ 2A 推荐 |

**信号引脚:
| 引脚 | 信号 | 说明 |
|------|------|------|
| A4, A9, B4, B9 | VBUS | 5V 电源输入 |
| A1, A12, B1, B12 | GND | 电源地 |
| A6, B6 | DP (D+) | USB D+ 数据线正极 |
| A7, B7 | DN (D-) | USB D- 数据线负极 |
| A5 | CC1 | 配置通道 1 |
| B5 | CC2 | 配置通道 2 |
| A2, A3, A10, A11, B10, B11 | SBU1/2 | 保留 |

### 2.2 反接保护电路 (NCE3401 P-MOSFET

```
USB-C VBUS 5V ────────┐
                    │
                    S (源极)
                    │
               NCE3401 P-MOSFET
                    │
                    D (漏极)
                    │
                    └───────→ VDD50 (至核心板和外设)
                    │
                   R11 10KΩ
                    │
                   GND
```

| 器件 | 型号 | 参数 | 功能 |
|------|------|------|------|
| Q3 | P-MOSFET | NCE3401 | SOT-23 | 反接保护 |
| R11 | 电阻 | 10KΩ 0402 | 栅极下拉电阻 |

**工作原理:**
- **正向连接 (USB 5V 正常输入):
  - Vgs = Vg - Vs = 0V - 5V = -5V < Vgs(th)
  - P-MOS 导通，VDD50 ≈ 5V - Rds(on)*I
- **反向连接 (电源反接):**
  - Vgs = 0V > Vgs(th)
  - P-MOS 截止，无电流通过

**保护机制:**
- 当 USB 线接反时，MOS 管完全截止，无电流流到后端电路

### 2.3 输入滤波

| 器件 | 参数 | 封装 | 功能 |
|------|------|------|------|
| C1 | 10uF/16V | 0805 | 大容量滤波 |
| C2 | 0.1uF/50V | 0402 | 高频去耦 |

## 三、CH340K USB 转串口芯片

### 3.1 CH340K 规格

| 参数 | 值 |
|------|-----|
| 型号 | CH340K |
| 封装 | SOP-16 |
| 功能 | USB 转 UART TTL |
| 供电 | 5V (VBUS) |
| 波特率 | 1200bps ~ 2Mbps |
| 内置晶振 | 是 (无需外部晶振) |
| 内置上电复位 | 是 |

### 3.2 CH340K 引脚连接 (关键引脚)

| CH340K 引脚 | 信号名 | 连接到 | 方向 | 功能 |
|------------|--------|------|------|
| 4 | V3 | 100nF 电容 → GND | 模拟 | 内置 3.3V 电源退耦 |
| 5 | UD+ | USB-C DP (D+) | 双向 | USB D+ |
| 6 | UD- | USB-C DN (D-) | 双向 | USB D- |
| 7 | VCC | USB 5V (VBUS) | 电源 | 5V 电源 |
| 8 | GND | 系统地 | 电源 | 地 |
| 9 | TXD | 核心板 P1-8 U0RXD (GPIO44) | 输出 | CH340 发送 → ESP32 接收 |
| 10 | RXD | 核心板 P1-7 U0TXD (GPIO43) | 输入 | CH340 接收 ← ESP32 发送 |
| 11 | DTR# | Q1 基极 → BOOT | 输出 | 数据终端就绪 → 烧录控制 |
| 12 | RTS# | Q2 基极 → EN | 输出 | 请求发送 → 烧录控制 |
| 13 | CTS# | GND 或悬空 | 输入 | 清除发送 (未使用) |
| 14 | RI# | 悬空 | 输入 | 振铃指示 (未使用) |
| 15 | DSR# | 悬空 | 输入 | 数据装置就绪 (未使用) |
| 16 | DCD# | 悬空 | 输入 | 数据载波检测 (未使用) |

### 3.3 串口交叉连接 (关键！)

```
CH340K TXD (引脚9) ───────→ 核心板 P1-8 → ESP32 U0RXD (GPIO44)
CH340K RXD (引脚10) ←─────── 核心板 P1-7 → ESP32 U0TXD (GPIO43)
```

> **说明:** 串口连接必须交叉（发送接接收，接收接发送
> 这是标准设计，确保 esptool.py 和 Arduino IDE 一键烧录正常工作

### 3.4 串口串联电阻

| 电阻 | 值 | 位置 | 功能 |
|------|-----|------|------|
| R4 | 22Ω | CH340K TXD 线路 | 阻抗匹配，防止过冲 |
| R5 | 22Ω | CH340K RXD 线路 | 阻抗匹配，防止过冲 |

## 四、一键下载电路 (自动烧录电路)

### 4.1 电路原理详解

```
VDD33 (来自核心板 3.3V)
│
├─ R7 (10KΩ) ──┐
│                ├────────────→ BOOT 网络 → 核心板 P2-2 → ESP32 GPIO0
├─ R8 (10KΩ) ──┤
│                └────────────→ CHIP_PU 网络 → 核心板 P2-1 → ESP32 EN
│
CH340K DTR# (引脚11) ── R3 (1KΩ) ── Q1 (SS8050 NPN) ── Collector → BOOT
│
Base ↓
Emitter → GND

CH340K RTS# (引脚12) ── R6 (1KΩ) ── Q2 (SS8050 NPN) ── Collector → CHIP_PU (EN)
│
Base ↓
Emitter → GND
```

### 4.2 器件清单

| 标识 | 器件 | 型号 | 参数 | 封装 | 数量 |
|------|------|------|------|------|
| Q1, Q2 | NPN 三极管 | SS8050 | SOT-23 | 2 |
| R3, R6 | 基极电阻 | 1KΩ | 0402 | 2 |
| R7, R8 | 上拉电阻 | 10KΩ | 0402 | 2 |

### 4.3 SS8050 三极管参数

| 参数 | 值 |
|------|-----|
| Vceo | 25V |
| Ic | 1.5A |
| hFE | 120~240 |
| Vce(sat) | 0.3V @ Ic=500mA |

### 4.4 烧录时序逻辑表

| 阶段 | CH340K DTR# | CH340K RTS# | Q1 | Q2 | ESP32 BOOT (GPIO0) | ESP32 EN (CHIP_PU) | 结果 |
|------|-----------|-----------|----|----|---------------------|-------------------|------|
| 正常运行 | 高 (3.3V) | 高 (3.3V) | 截止 | 截止 | 高 (3.3V 上拉) | 高 (3.3V 上拉) | 正常运行 |
| 准备烧录 | 低 (0V) | 高 (3.3V) | 导通 | 截止 | **低 (0V) | 高 (3.3V) | BOOT=0 进入烧录模式准备 |
| 复位触发 | 低 (0V) | 低 (0V) | 导通 | 导通 | 低 (0V) | **低 (0V) | 芯片复位 |
| 退出复位 | 低 (0V) | 高 (3.3V) | 导通 | 截止 | 低 (0V) | 高 (3.3V) | 以下载模式启动 |
| 开始烧录 | 低 (0V) | 高 (3.3V) | 导通 | 截止 | 低 (0V) | 高 (3.3V) | 发送固件数据 |

### 4.5 esptool.py 工作流程

```bash
1. esptool.py 打开串口设备
2. 设置 DTR=0, RTS=1  → BOOT=0, EN=1  (准备下载模式
3. 等待 50ms
4. 设置 DTR=0, RTS=0  → BOOT=0, EN=0  (复位芯片
5. 等待 50ms
6. 设置 DTR=0, RTS=1  → BOOT=0, EN=1  (芯片以下载模式启动
7. 开始发送固件数据 (使用 ROM Bootloader 通信
```

> **功能验证:** 此电路支持:
- ✅ `idf.py flash` 一键烧录
- ✅ Arduino IDE 一键上传
- ✅ `esptool.py 自动烧录
- ✅ 无需手动按 BOOT 按键
```

### 5.4 供电流向图

```
底板 USB-C 5V
│
↓
NCE3401 反接保护
│
├──────────────────────────┐
↓                          ↓
VDD50 总线               NS4150B 功放 (核心板上)
│
↓
P1-1/2 → 核心板
│
↓
核心板 ME6217C33 LDO (5V→3.3V)

↓                          ↓

## 六、外部扩展接口 (P3 I2C + P4 UART

### 6.1 I2C 扩展接口 P3 (4Pin 2.54mm 排针)

| 引脚号 | 信号名 | 连接到 | 电压 | 功能 |
|--------|--------|--------|------|------|
| P3-1 | VDD50 | USB 5V → 反接保护后 | 5V | 外部设备电源 |
| P3-2 | GND | 系统地 | GND | 电源地 |
| P3-3 | SDA | P1-5 → 核心板 GPIO41 | 3.3V 电平 | I2C 数据线 (与摄像头/ES8311 共享总线) |
| P3-4 | SCL | P1-6 → 核心板 GPIO42 | 3.3V 电平 | I2C 时钟线 (与摄像头/ES8311 共享总线) |

#### I2C 上拉电阻

| 电阻 | 值 | 位置 |
|------|-----|------|
| R12 | 4.7KΩ | SDA 上拉 → VDD33 |
| R13 | 4.7KΩ | SCL 上拉 → VDD33 |

#### I2C 总线架构

```
ESP32 GPIO41 (SDA) ────────┬────────── 摄像头 SIOD
│
├────────── ES8311 CDATA
│
└────────── P3-3 (外部 I2C)

ESP32 GPIO42 (SCL) ───────┬────────── 摄像头 SIOC
│
├────────── ES8311 CCLK
│
└────────── P3-4 (外部 I2C)
```

**I2C 使用注意事项:**
1. 总线上已有设备地址不冲突:
- 摄像头 GC2145/OV2640: 0x78/0x60 (写)
- ES8311 音频 Codec: 0x30 (8-bit I2C 地址)
- 外部设备地址自定义
2. 外部设备必须支持 3.3V 电平
3. 底板已有 R12/R13 4.7K 上拉 + 核心板 R1/R2 10K 上拉
- 总上拉 ≈ 3.2KΩ，符合 I2C 标准
4. 外部设备请勿再加额外上拉

### 6.2 UART 扩展接口 P4 (4Pin 2.54mm 排针)

| 引脚号 | 信号名 | 连接到 | 电压 | 功能 |
|--------|--------|--------|------|------|
| P4-1 | VDD50 | USB 5V → 反接保护后 | 5V | 外部设备电源 |
| P4-2 | GND | 系统地 | GND | 电源地 |
| P4-3 | ESP_N | P2-7 → 核心板扩展串口 RX | 3.3V 电平 | ESP32 UART 接收 (外部设备 TX → ESP32 RX) |
| P4-4 | ESP_P | P2-8 → 核心板扩展串口 TX | 3.3V 电平 | ESP32 UART 发送 (ESP32 TX → 外部设备 RX) |

#### UART 交叉连接规则

```
底板 P4-3 (ESP_N / RX) ←─────── 外部模块 TX
底板 P4-4 (ESP_P / TX) ───────→ 外部模块 RX
```

> **默认状态:** 出厂时 UART0 (GPIO43/44) 用于 CH340K USB 串口
> 扩展 UART 可配置为 UART1 或 UART2，需在软件中映射到可用 GPIO

**可用 GPIO 映射建议:**
- ESP_N (RX): 可映射到 GPIO4/5/6/7 等
- ESP_P (TX): 可映射到 GPIO4/5/6/7 等

## 七、电源指示灯 LED

### 7.1 LED 电路

```
核心板 P2-5 (VDD33) ──────── R_LED (1KΩ) ──────── LED1 (D1) ──────── GND
```

### 7.2 器件参数

| 器件 | 型号/参数 | 封装 |
|------|----------|------|
| LED1 (D1) | 红色 LED | 0603 |
| R_LED | 1KΩ | 0402 |

**工作电流:**
```
Vf = 1.8V ~ 2.0V (红色 LED 正向压降
I = (VDD33 - Vf) / R_LED = (3.3V - 1.8V ~ 1.5mA
```

> **说明:** 当核心板 LDO 正常输出 3.3V 时，LED 点亮
> 这是底板唯一的 LED 指示灯

## 九、底板电气规格

### 9.1 电源规格

| 参数 | 最小值 | 典型值 | 最大值 | 单位 |
|------|-------|-------|-------|------|
| 输入电压 | 4.5 | 5.0 | 5.5 | V |
| 输入电流 | - | 500 | 2000 | mA |
| 5V 输出 (核心板+扩展) | - | - | 1500 | mA |
| 3.3V 输出 (来自核心板) | - | - | 150 | mA |

### 9.2 接口电平标准

| 接口 | 电平标准 | 容忍 5V? |
|------|---------|---------|
| I2C (SDA/SCL) | 3.3V | ❌ 否，不可接 5V 设备 |
| UART (ESP_N/ESP_P) | 3.3V | ❌ 否，不可接 5V 设备 |
| 电源引脚 (VDD50/GND) | 5V | ✅ 是 |

> **⚠️ 警告:**
> 底板所有信号均为 3.3V 电平！
> 连接 5V 串口设备会损坏 ESP32 芯片
> 如需连接 5V 设备必须外接电平转换模块！

## 十一、常见硬件问题排查

### 11.1 烧录失败检查清单

```
问题: 无法烧录固件
├─ 检查 1: USB 线是否为数据线 (有些只有供电)
│
├─ 检查 2: CH340 驱动是否安装正确
│
├─ 检查 3: 核心板是否插到底板 (排针对齐)
│
├─ 检查 4: 电源 LED 是否点亮
│
├─ 检查 5: BOOT (GPIO0) 上拉电阻 R7 是否焊接
│
├─ 检查 6: EN (CHIP_PU) 上拉电阻 R8 是否焊接
│
├─ 检查 7: Q1/Q2 三极管是否焊反 (引脚朝向)
│
└─ 检查 8: 尝试手动烧录 (按住 BOOT 按复位，松开复位后松 BOOT
```

### 11.2 串口无输出检查清单

```
问题: 串口监视器无输出
├─ 检查 1: 波特率设置是否正确 (默认 115200)
│
├─ 检查 2: TX/RX 是否交叉 (CH340 TXD → ESP32 URXD)
│
├─ 检查 3: CH340K 焊接是否良好 (无虚焊)
│
└─ 检查 4: ESP32 是否正常启动 (3.3V 是否正常)
```

### 11.3 I2C 设备无法识别检查清单

```
问题: 外部 I2C 设备无法识别
├─ 检查 1: SDA/SCL 是否接反
│
├─ 检查 2: 外部设备是否为 3.3V 电平
│
├─ 检查 3: I2C 地址是否与摄像头/ES8311 冲突
│
├─ 检查 4: 总线上拉 R12/R13 是否焊接
│
└─ 检查 5: 摄像头是否已初始化并占用总线
```
