# ESP32-NanoCam 固件架构设计

> 多Agent融合：模式A（离线边缘AI视觉）+ 模式B（XiaoZhi AI）+ 模式C（ESP-Claw）
>
> 基于 ESP-IDF 5.4+, ESP32-S3 N16R8 (16MB Flash / 8MB PSRAM)

---

## 一、顶层架构

```
                       app_main()
                           │
                    ┌──────┴──────┐
                    │  NVS Flash  │  读取 WiFi 配置 + AI_Mode
                    │  初始化     │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
         WiFi Init    Camera Init   Protocol Init
         (AP/STA)     (GC2145)     (Serial/I2C)
              │            │            │
              └────────────┼────────────┘
                           │
                    ┌──────┴──────┐
                    │  AI_Mode ?  │  从 Flash 读取当前模式
                    └──────┬──────┘
                           │
          ┌────────────────┼────────────────┬──────────────┐
          ▼                ▼                ▼              ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ Mode 0~5 │    │ Mode 6   │    │ Mode 7   │    │ Default  │
    │ 视觉模式  │    │ XiaoZhi  │    │ ESP-Claw │    │ Mode 0   │
    └────┬─────┘    └────┬─────┘    └────┬─────┘    └──────────┘
         │               │               │
    ┌────┴────┐    ┌─────┴──────┐   ┌────┴──────────┐
    │ AI Task │    │Application │   │ nano_espclaw   │  ESP-Claw桥接
    │ HTTPD   │    │  ::Start() │   │  ::Start()     │  MCP+YAML+Lua
    │ Serial  │    └────────────┘   └───────────────┘
    └─────────┘
```

## 二、分区表设计 (16MB Flash)

```
# partitions_nanocam.csv
# 16MB (0x1000000) Flash layout
# Name      Type        SubType     Offset      Size        Flags
nvs,        data,       nvs,        0x9000,     0x6000,     # 24KB
otadata,    data,       ota,        0xf000,     0x2000,     # 8KB
factory,    app,        factory,    0x10000,    0x300000,   # 3MB
ota_0,      app,        ota_0,      0x310000,   0x300000,   # 3MB
ota_1,      app,        ota_1,      0x610000,   0x300000,   # 3MB
spiffs,     data,       spiffs,     0x910000,   0x300000,   # 3MB (Web后台 + 资源)
model,      data,       fat,        0xC10000,   0x3F0000,   # ~4MB (AI模型 + 人脸库)
```

| 分区 | 大小 | 用途 |
|------|------|------|
| **nvs** | 24KB | WiFi配置 / AI_Mode / 用户设置 |
| **otadata** | 8KB | OTA 状态标记 |
| **factory** | 3MB | 出厂固件（含多Agent AI） |
| **ota_0** | 3MB | OTA 槽位 A |
| **ota_1** | 3MB | OTA 槽位 B |
| **spiffs** | 3MB | Web管理后台前端 + 小智AI多语言资源(.p3) |
| **model** | ~4MB | ESP-DL模型权重 + ESP-WHO人脸特征库 |

> **为什么需要 3 个 app 分区**：factory 保证永不 brick；ota_0/1 支持安全回滚。
>
> **为什么 model 用 FAT**：方便通过 USB MSC 或串口直接替换模型文件。

## 四、FreeRTOS 任务规划

### 4.1 模式A（视觉模式）任务

| 任务名 | 优先级 | 栈 | 核心 | 功能 |
|--------|:--:|------|:--:|------|
| `camera_task` | 5 | 4KB | 1 | 摄像头帧抓取 → Queue |
| `ai_process` | 4 | 6KB | 1 | AI推理 (猫脸/人脸/颜色/QR/运动) |
| `httpd_mjpeg` | 3 | 8KB | 0 | HTTP MJPEG 流推送 |
| `serial_cmd` | 2 | 5KB | 0 | 串口 AT 指令处理 |
| `i2c_slave` | 2 | 3KB | 0 | I2C 从机响应 |
| `mqtt_client` | 2 | 6KB | 0 | MQTT 连接+上报 |
| `idle` | 0 | — | — | 系统空闲 |

### 4.2 模式B（XiaoZhi AI）任务（继承小智AI架构）

| 任务名 | 优先级 | 栈 | 核心 | 功能 |
|--------|:--:|------|:--:|------|
| `audio_input` | 5 | 8KB | 1 | I2S 麦克风采集 + Opus编码 |
| `audio_output` | 4 | 8KB | 1 | Opus解码 + I2S 功放输出 |
| `wake_word` | 4 | 6KB | 0 | ESP-SR 唤醒词检测 |
| `ws_protocol` | 3 | 8KB | 0 | WebSocket 通信 (ASR/LLM/TTS) |
| `mcp_server` | 3 | 6KB | 0 | MCP JSON-RPC 处理 |
| `lvgl_timer` | 2 | 8KB | 0 | LVGL 显示刷新 |
| `bg_task` | 1 | 4KB | 0 | 后台任务(OTA/电量/网络检测) |

### 4.3 模式C（ESP-Claw）任务

| 任务名 | 优先级 | 栈 | 核心 | 功能 |
|--------|:--:|------|:--:|------|
| `claw_agent` | 4 | 12KB | 0 | ESP-Claw Agent 主循环 (事件驱动) |
| `claw_mcp` | 3 | 6KB | 0 | MCP 工具注册+JSON-RPC 调度 |
| `claw_im` | 3 | 8KB | 0 | IM 通道 (微信/飞书/钉钉 WebSocket) |
| `lua_vm` | 2 | 12KB | 0 | Lua 脚本引擎 (动态加载) |
| `claw_camera` | 2 | 6KB | 1 | Lua 摄像头模块 (拍照/流式) |
| `bg_task` | 1 | 4KB | 0 | 后台任务(OTA/电量/网络检测) |

### 4.4 核心绑定策略

```
Core 0 (Protocol Core)        Core 1 (Application Core)
─────────────────────────     ─────────────────────────
WiFi 事件处理                 摄像头帧抓取 (DVP)
HTTP Server                    AI 推理 (ESP-DL/WHO)
WebSocket/MQTT 协议            Opus 编解码
IM 通道 (ESP-Claw)             I2S 音频输入/输出
LVGL 显示                     Lua 摄像头模块
串口 AT 指令
MCP Server
Lua VM (ESP-Claw)
后台任务
```

## 五、内存规划 (8MB PSRAM)

```
PSRAM (8MB)                          SRAM (~512KB)
─────────────────────────────        ─────────────────
Camera FB1:  640×480×2 = 600KB      System:      ~200KB
Camera FB2:  640×480×2 = 600KB      LWIP stack:   ~50KB
JPEG Buffer:           = 256KB      FreeRTOS:    ~100KB
LVGL Display Buffer:   = 300KB      App stacks:  ~150KB
AI Model (ESP-DL):     = 2MB        ─────────────────
Face DB (ESP-WHO):     = 512KB      Total free:  ~12KB
Opus Audio Buffer:     = 128KB
Lua VM (ESP-Claw):     = 512KB
SPIFFS Cache:          = 256KB
Misc (HTTP/WS/MQTT):   = 512KB
─────────────────────────────
PSRAM Used:  ~5.6MB
PSRAM Free:  ~2.4MB
```

> **关键约束**：ESP-DL 模型必须驻留在 PSRAM 中（SRAM 装不下）。确保 `CONFIG_SPIRAM_MALLOC_ALWAYSINTERNAL=4096` 预留足够内部 SRAM 给系统栈。

## 六、DMA 通道分配

| 外设 | DMA | GPIO 组 | 冲突检查 |
|------|-----|---------|:--:|
| **LCD_CAM (DVP)** | GDMA Ch0 | IO29-39 | ✅ 独立 |
| **I2S0 (麦克风)** | GDMA Ch1 | IO40-42 | ✅ 独立 |
| **I2S1 (保留)** | GDMA Ch2 | — | 预留, GPIO45-47 空闲 |
| **SPI2 (Flash)** | GDMA Ch3 | IO29-34 | ✅ 独立 |
| **SPI3 (LCD)** | (可选) | — | 如果启用LCD |

> ESP32-S3 有 5 个 GDMA 通道 + 专用 LCD_CAM DMA，本设计仅使用 4 个，互不冲突。

## 七、多Agent切换机制

### 7.1 切换流程

```
用户发送: ai_mode:6   (或 ai_mode:7)
         │
         ▼
   serial_cmd 任务接收
         │
    ┌────┴────┐
    │ 写 NVS  │  保存新 AI_Mode
    └────┬────┘
         │
    ┌────┴────┐
    │ 释放当前│  停止 HTTPD / AI Task
    │ 模式资源│  或停止 Application / WS / Claw Agent
    └────┬────┘
         │
    ┌────┴────┐
    │ esp_    │  软复位 (~500ms)
    │ restart │
    └─────────┘
         │
    app_main() 再次执行
         │
    读 NVS → AI_Mode=6 (或 7)
         │
    ┌────┴──────────────────────┐
    │ Mode 6: 初始化             │  Mode 7: 初始化
    │ WiFi + Camera             │  WiFi + Camera
    │ + Application + MCP       │  + ESP-Claw Agent + MCP
    │ + Audio + LVGL            │  + IM + Lua
    └──────────────────────────┘
```

### 7.2 为什么需要重启

1. **内存碎片**：模式A 和 模式B 的内存占用模式完全不同，直接切换会导致 PSRAM 碎片化
2. **DMA 重配置**：I2S DMA 需要完全释放再重新分配
3. **WiFi 状态**：模式B 需要保持 WebSocket 长连接，模式A 不需要
4. **简化实现**：重启仅需 ~500ms，用户体验无感知

## 八、引脚配置 (Kconfig)

```kconfig
# main/Kconfig.projbuild

menu "NanoCam Configuration"

    choice NANOCAM_CAMERA_MODEL
        prompt "Camera Sensor"
        default NANOCAM_CAMERA_GC2145
        config NANOCAM_CAMERA_GC2145
            bool "GC2145 (default)"
        config NANOCAM_CAMERA_OV2640
            bool "OV2640 (2MP)"
        config NANOCAM_CAMERA_OV5640
            bool "OV5640"
        config NANOCAM_CAMERA_GC2145
            bool "GC2145"
    endchoice

    config NANOCAM_ENABLE_AUDIO
        bool "Enable Audio (Mic + Speaker)"
        default y
        help
            ES8311 Codec + AP2718AT Mic + NS4150B Amp.
            Disable to save PSRAM if only using vision modes.

    config NANOCAM_ENABLE_LLM
        bool "Enable XiaoZhi AI Agent (Mode 6)"
        default y
        help
            Voice chat + Visual understanding via xiaozhi.me.
            Requires ~3MB additional flash for assets.

    config NANOCAM_ENABLE_ESPCLAW
        bool "Enable ESP-Claw Agent (Mode 7)"
        default n
        help
            Chat-as-Creation via IM (WeChat/Lark) + Lua + MCP.
            Requires esp_board_manager + esp-claw components.

    config NANOCAM_ENABLE_MQTT
        bool "Enable MQTT Client"
        default y

    config NANOCAM_ENABLE_I2C_SLAVE
        bool "Enable I2C Slave Mode"
        default y

    config NANOCAM_DEFAULT_AI_MODE
        int "Default AI Mode on boot"
        range 0 7
        default 0
        help
            0=Stream 1=Cat 2=Face 3=Color 4=FaceID 5=QR 6=XiaoZhi 7=ESP-Claw

endmenu
```

> 所有摄像头/音频引脚已在 `nano_config.h` 中硬编码为 NanoCam 原理图值，无需 Kconfig 配置引脚。

## 九、错误处理策略

| 故障 | 检测 | 处理 |
|------|------|------|
| 摄像头初始化失败 | `esp_camera_init() != ESP_OK` | LED 快闪 3 次 / 串口报错 / 跳过AI 仅 WiFi |
| WiFi 连接失败 | 超时 30s | 降级为 AP 模式 / LED 慢闪 |
| PSRAM 不足 | `malloc()` 返回 NULL | 降级分辨率 (VGA→QVGA) / 关闭音频 |
| WebSocket 断开 (小智) | `OnDisconnected()` | 自动重连 (指数退避, 最多 5 次) |
| IM 通道断开 (ESP-Claw) | WebSocket 超时 | 自动重连 + 本地缓存未发送消息 |
| Lua 脚本异常 (ESP-Claw) | Lua VM 错误回调 | 日志记录 / 回退到默认行为 / 不重启 |
| Flash 写入失败 | NVS 返回错误 | 使用默认值 / 标记损坏 |
| OTA 校验失败 | 签名/CRC 不匹配 | 回滚到上一个固件 |
| 模型加载失败 | ESP-DL 返回 NULL | 串口报错 / 跳过该 AI 模式 |
| 栈溢出 | FreeRTOS 检测 | 重启 / 增加栈大小 |

### LED 状态指示

| LED 状态 | 含义 |
|---------|------|
| 常亮 | 正常工作 |
| 快闪 (200ms) | WiFi 连接中 / 配网模式 |
| 慢闪 (1s) | AP 模式运行中 |
| 闪 3 次 | 摄像头故障 |
| 闪 5 次 | PSRAM/Flash 故障 |

## 十、构建配置矩阵

| 场景 | Kconfig | Flash | PSRAM |
|------|---------|-------|-------|
| 完整多Agent | 全部开启 | ~8MB | ~5MB |
| XiaoZhi AI + 视觉 | `NANOCAM_ENABLE_ESPCLAW=n` | ~6MB | ~4MB |
| ESP-Claw + 视觉 | `NANOCAM_ENABLE_LLM=n` `NANOCAM_ENABLE_AUDIO=n` | ~4MB | ~3.5MB |
| 仅视觉模式 | `NANOCAM_ENABLE_LLM=n` `NANOCAM_ENABLE_ESPCLAW=n` `NANOCAM_ENABLE_AUDIO=n` | ~3MB | ~3MB |
| 最小系统 | 仅 WiFi + 图传 | ~1.5MB | ~1MB |
