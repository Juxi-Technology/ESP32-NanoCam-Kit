# NanoCam 版本号规范

## 格式: 语义化版本

```
v<MAJOR>.<MINOR>.<PATCH>[-<PRE>]

v1.2.3-beta
```

| 字段 | 变更条件 |
|------|---------|
| MAJOR | 不兼容的 API 修改 |
| MINOR | 向下兼容的功能新增 |
| PATCH | 向下兼容的问题修复 |
| PRE | alpha / beta / rc1 |

## 示例

| 版本 | 说明 |
|------|------|
| v0.1.0 | 初始骨架, 未编译 |
| v0.2.0 | Phase1+2: 摄像头+WiFi+HTTP+AI调度 |
| v1.0.0 | 首个稳定版, 7种AI模式全部验证 |
| v1.1.0 | 新增 MQTT 客户端 |
| v1.2.0 | 新增 LLM 智能体集成 |

## 发布分支

```
master ← 稳定版本
  ↑
dev  ← 开发分支
  ↑
feature/xxx ← 功能分支
```
