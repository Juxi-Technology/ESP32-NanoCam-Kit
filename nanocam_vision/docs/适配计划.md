## 一、产品定位：多Agent AI相机

### 核心理念

**NanoCam 是全球首个「多Agent AI相机」** —— 同一个硬件，两种工作模式：

```
┌─────────────────────────────────────────────┐
│              NanoCam 多Agent架构                │
│                                             │
│  模式A: 离线AI视觉模组 (Edge AI)             │
│  ┌──────────────────────────────────┐       │
│  │ 7种边缘AI → 串口/HTTP输出        │       │
│  │ 不联网也能工作，毫秒级响应        │       │
│  │ 对标: OpenMV / HuskyLens         │       │
│  └──────────────────────────────────┘       │
│                                             │
│  模式B: 双Agent智能体 (Cloud AI)             │
│  ┌──────────────────────────────────┐       │
│  │ ai_mode:6 = XiaoZhi AI (语音对话) │       │
│  │ ai_mode:7 = ESP-Claw (聊天造物)   │       │
│  │ 语音+视觉+IM+Lua+MCP             │       │
│  └──────────────────────────────────┘       │
│                                             │
│  串口切换: ai_mode:6 / ai_mode:7            │
└─────────────────────────────────────────────┘
```

### 核心卖点

| 维度 | 定位 |
|------|------|
| **一句话** | 既能离线跑7种AI视觉，又能联网变身LLM智能体——一个固件两种人生 |
| **最大差异化** | **多Agent AI**：市面上没有任何同类产品同时具备边缘AI视觉 + LLM语音对话能力 |
| **对标** | 模式A vs OpenMV/HuskyLens/NanoCam；模式B vs 小智AI/智能音箱 |

### 目标用户（多Agent覆盖更广）

| 人群 | 模式A（视觉模组） | 模式B（LLM智能体） |
|------|-----------------|-------------------|
| 创客/极客 | 快速搭建AI视觉原型 | DIY一个能聊天的AI伙伴 |
| 教育机构 | 7个AI视觉递进教程 | LLM+硬件入门教学 |
| 机器人爱好者 | 串口坐标输出接机械臂 | 语音控制机器人 |
| 嵌入式工程师 | 开源协议栈参考 | MCP协议二次开发 |
| 产品公司 | 视觉检测模组OEM | AI语音助手OEM |
| **新增** AI爱好者 | — | 体验大模型+摄像头的多模态交互 |

### 一句话定位

> **NanoCam** — 离线能看、联网能聊。7种边缘AI + 云端LLM，一个固件搞定所有。

## 二、功能全景（多Agent）

### 2.1 模式A: 离线AI视觉模组（7种边缘AI）

| 模式 | 名称 | 功能 | 输出 | 来源 |
|------|------|------|------|------|
| 0 | 正常模式 | MJPEG 实时图传 | HTTP 视频流 | NanoCam |
| 1 | 猫脸检测 | 猫脸框 + 置信度 | 标注画面 + 串口坐标 | NanoCam |
| 2 | 人脸检测 | 人脸框 + 坐标输出 | 标注画面 + 串口坐标 | NanoCam |
| 3 | 颜色识别 | 框选录入色块→实时检测 | 标注画面 + 串口坐标 | NanoCam |
| 4 | 人脸识别 | 注册人脸→辨认→删除 | 标注画面 + 辨认结果 | NanoCam |
| 5 | 二维码 | 实时解码→串口透传 | `$data#` 格式输出 | NanoCam |
| 6 | **运动检测** | 帧差法→运动报警 | GPIO/MQTT 通知 | **新增** |

### 3.3 多模式通信协议全集

**串口 AT 指令（兼容 NanoCam + LLM扩展）**：

| 指令 | 功能 | 模式 |
|------|------|------|
| `sta_ssid:X` `sta_pd:X` | STA WiFi | A+B |
| `ap_ssid:X` `ap_pd:X` | AP 热点 | A+B |
| `wifi_mode:0/1/2` | WiFi 模式 | A+B |
| `ai_mode:0~5` | 边缘AI模式切换 | A |
| `ai_mode:6` | **切换到LLM智能体模式** | B |
| `sta_ip` `ap_ip` | 查询IP | A+B |
| `wifi_reset` `wifi_ver` | 重置/版本 | A+B |
| `KEY_MENU/PLAY/UPUP/DOWN` | 虚拟按键(颜色/人脸) | A |
| `nano_mqtt:HOST,PORT,TOPIC` | MQTT 配置 | A+B |
| `nano_ota:URL` | OTA 升级 | A+B |
| `nano_led:R,G,B` | RGB LED | A+B |
| `nano_snap` | 拍照存TF | A+B |
| `nano_stream:ON/OFF` | 图传开关 | A |
| `nano_reboot` | 软复位 | A+B |
| `nano_info` | 完整 JSON 信息 | A+B |
| `nano_server:URL` | **LLM服务器地址** | B |

**MCP 协议（模式B专属，JSON-RPC 2.0 over WebSocket/MQTT）**：

| 方法 | 功能 |
|------|------|
| `initialize` | 初始化MCP会话，下发视觉解释URL |
| `tools/list` | 获取设备所有可调用工具列表 |
| `tools/call` | 调用具体工具（拍照/设音量/控GPIO等） |

**I2C 从机寄存器**：

| 地址 | 内容 | 说明 |
|------|------|------|
| 0x00 | 版本号 | 主<<8\|次 |
| 0x01 | 当前模式 | 0~7 |
| 0x02-03 | X坐标 | uint16 LE |
| 0x04-05 | Y坐标 | uint16 LE |
| 0x06-07 | 宽度 | uint16 |
| 0x08-09 | 高度 | uint16 |
| 0x0A | 检测数 | 0=无 |
| 0x20 | 写模式 | Write only |
| 0x30-4F | 结果字符串 | 32B |
