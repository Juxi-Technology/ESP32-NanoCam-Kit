# NanoCam 技术白皮书

> 多Agent AI相机：从边缘推理到云端大模型的融合架构

---

## 摘要

NanoCam 基于 ESP32-S3 N16R8 芯片，在同一硬件上实现了两种AI范式：离线边缘推理（7种视觉检测模式）和云端大模型交互（语音对话+视觉理解）。本文阐述其技术架构、核心创新和性能指标。

## 1. 硬件平台

| 参数 | 规格 |
|------|------|
| MCU | ESP32-S3, 双核 Xtensa LX7 @240MHz |
| PSRAM | 8MB Octal SPI |
| Flash | 16MB (GD25Q128ESIG) |
| 摄像头 | GC2145 (默认) / OV2640 / OV5640 |
| 音频 | ES8311 Codec + AP2718AT Mic + NS4150B Amp |
| RGB LED | WS2812 (GPIO18) |

## 2. 多Agent AI架构

### 模式A: 边缘推理
- **猫脸检测**: CatFaceDetectMN03 (基于 MobileNetV3)
- **人脸检测**: ESP-DL (基于 MobileNet 的轻量级检测)
- **人脸识别**: ESP-WHO (特征提取 + 欧氏距离比对)
- **颜色识别**: HSV 色彩空间色块检测
- **二维码**: esp-code-scanner 实时解码
- 推理耗时: ~100ms/帧 (QVGA 320x240)
- PSRAM 占用: ~5.1MB (含模型权重 + 帧缓冲)

### 模式B: 云端LLM
- **语音链路**: 麦克风 → Opus 编码 → WebSocket → ASR → LLM → TTS → 扬声器
- **视觉理解**: 摄像头 JPEG → HTTP 上传 → 多模态 LLM 分析 → 文字描述
- **设备控制**: MCP 协议 (JSON-RPC 2.0)，LLM 自动发现并调用设备工具
- 服务器: xiaozhi.me 或自部署 xiaozhi-esp32-server

## 3. FreeRTOS 任务规划

| 核心0 (协议) | 核心1 (计算) |
|---|---|
| WiFi 事件处理 | 摄像头 DVP DMA 帧抓取 |
| HTTP Server (MJPEG) | AI 推理 (ESP-DL/ESP-WHO) |
| WebSocket / MQTT | JPEG 编码 (fmt2jpg) |
| 串口 AT 指令 | |
| LVGL 显示刷新 | |

## 4. 通信协议栈

| 接口 | 协议 | 用途 |
|------|------|------|
| 串口 UART0 | AT 指令 (115200 8N1) | WiFi/AI 模式配置 |
| I2C 从机 | 寄存器读写 (addr 0x33) | 外部 MCU 读取 AI 结果 |
| HTTP | MJPEG 流 + REST API | 浏览器实时观看 + 控制 |
| WebSocket | JSON 消息 | LLM 实时对话 |
| MQTT | JSON 推送 | 检测结果上报云端 |
| UDP | micro-ROS | ROS2 图像/检测话题发布 |

## 5. 性能优化

- **JPEG 缓冲池**: 预分配 32KB PSRAM 复用，消除每帧 malloc/free
- **帧跳过**: 队列满时自动丢弃旧帧，避免摄像头阻塞
- **串口事件驱动**: `uart_read_bytes(portMAX_DELAY)` 替代轮询
- **队列深度**: 4 帧缓冲，多客户端场景帧丢失率减半
