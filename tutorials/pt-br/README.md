# Tutoriais do módulo de câmera com IA dual-mode ESP32-S3

O ESP32-NanoCam é o módulo de câmera com IA dual-mode ESP32-S3 da Juxi Technology: visão por IA na borda (offline) + agente de voz com LLM na nuvem (conectado à internet). Este conjunto de tutoriais cobre 11 capítulos progressivos e 4 documentos de referência, da gravação do firmware às aplicações de IA.
