## 四、音訊子系統

### 4.1 音訊架構

```
AP2718AT (類比MEMS麥) → ES8311 Codec (ADC/DAC) → NS4150B (類比功放) → 揚聲器
                               ↕ I2S (MCLK=39,BCLK=38,WS=47,DOUT=48,DIN=40) + I2C (41/42, addr=0x30)
                            ESP32-S3
```

| 元件 | 型號 | 類型 | 介面 |
|---|---|---|---|
| 麥克風 | **AP2718AT** | 類比 MEMS 矽麥 | 差分類比 → ES8311 ADC |
| 編解碼器 | **ES8311** | 音訊 Codec（I2S+I2C） | I2S=MCLK=39,BCLK=38,WS=47,DOUT=48,DIN=40, I2C=41/42, addr=0x30 |
| 功放 | **NS4150B** | D 類類比功放 | ES8311 DAC 輸出 → 類比輸入 → 揚聲器 |

### 4.2 ES8311 Codec I2S 引腳

| I2S 信號 | ESP32 GPIO | 功能 |
|---|---|---|
| MCLK | **IO39** | 主時鐘 |
| BCLK (SCLK) | **IO38** | 位時鐘 |
| LRCLK (WS) | **IO47** | 左右聲道時鐘 |
| DOUT (DAC) | **IO48** | 串列數據輸出（播放） |
| DIN (ADC) | **IO40** | 串列數據輸入（錄音） |

> 音訊使用 I2S0 Standard Duplex 模式，ES8311 Codec 同時支援錄音與播放。

### 4.3 ES8311 I2C 控制

| I2C 信號 | GPIO | 說明 |
|---|---|---|
| SDA | IO41 | 與攝影機共用 I2C 總線 |
| SCL | IO42 | 與攝影機共用 I2C 總線 |
| 地址 | **0x30** | ES8311 8-bit I2C 地址 |

## 五、電源系統

### 5.1 供電鏈路

```
USB-C (5V) ──→ 底板 NCE3401 P-MOSFET 反接保護 ──→ VDD50
                                              │
                    ┌─────────────────────────┤
                    ↓                         ↓
            核心板 ME6217C33 LDO            NS4150B 功放
                    │                  (5V 直供)
                    ↓
                 VDD33 (3.3V)
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
    ESP32-S3    ES8311 Codec   GD25Q128 Flash
    DVP攝影機   AP2718AT 麥    ME6211A18/28 LDO
```

### 5.2 關鍵元件

| 芯片 | 型號 | 功能 |
|---|---|---|
| LDO | **ME6217C33P5G** (SOT-89-5) | 5V→3.3V 穩壓 |
| LDO | **ME6211A18M3G** (SOT-23) | 5V→1.8V（攝影機核心） |
| LDO | **ME6211A28M3G** ×2 (SOT-23) | 5V→2.8V（U6=AVDD, U7=DOVDD） |
| U1 輸入濾波 | C14 (10μF) + C15 (0.1μF) | ME6217C33 輸入 |
| U1 輸出濾波 | C1 (22μF) | ME6217C33 輸出 |
| 反接保護 | **NCE3401** P-MOSFET | 底板電源輸入保護 |
| 閘極電阻 | R11 10KΩ | P-MOS 閘極接地 |

## 六、底板與燒錄

### 6.1 USB 轉串列

| 參數 | 規格 |
|---|---|
| 芯片 | **CH340K** |
| USB 介面 | USB-C（USB1） |
| 串列連接 | TXD→U0RXD (IO44), RXD→U0TXD (IO43)（交叉） |
| USB 匹配電阻 | R4, R5 22R/1%（D+/D- 串聯） |
| DTR/RTS | 一鍵燒錄自動控制 BOOT + EN |

### 6.2 一鍵下載電路

使用 Q1、Q2（S8050 NPN 三極體）實現自動燒錄：

| CH340K 信號 | 控制 | 目標引腳 |
|---|---|---|
| DTR | → Q1 → | ESP32 **EN** (CHIP_PU) |
| RTS | → Q2 → | ESP32 **BOOT** (IO0) |

> 原理：USB 燒錄工具透過 DTR/RTS 翻轉自動控制 BOOT 和 EN 時序，無需手動按鍵。

## 八、關鍵設計約束

### 8.1 I2S 周邊設定

- ESP32-S3 有兩個 I2S 控制器：
  - **I2S0**：已分配給 ES8311 Codec（MCLK=IO39, BCLK=IO38, WS=IO47, DOUT=IO48, DIN=IO40），雙向 I2S Duplex，同時支援錄音與播放
- ES8311 I2C 控制：SDA=IO41, SCL=IO42, 元件地址 0x30

### 8.2 DVP 與 I2S DMA 共存

- DVP 使用 **LCD_CAM** 周邊的 DMA 通道
- ES8311 使用 I2S0 DMA（單一 I2S 介面雙向）
- 兩者不衝突，但需注意 PSRAM 頻寬（8MB PSRAM 足夠）
- GPIO45/46 與音訊無連接，可作其他用途；GPIO47 用於 I2S WS

### 8.3 I2C 總線共享

- IO41(SDA) + IO42(SCL) 同時連接攝影機與外部 I2C 介面
- I2C 上拉電阻：R12（SDA, 4.7K/1%）、R13（SCL, 4.7K/1%），上拉至 VDD33
- 需確保攝影機 I2C 地址與外部裝置不衝突
- OV2640 預設 I2C 地址：0x60（寫）/ 0x61（讀）— 與 ES8311（0x30）不衝突

### 8.4 Flash 容量充足

- **16MB Flash** 空間充裕，可支援：
  - OTA 雙分區方案（factory + ota_0 + ota_1）
  - SPIFFS 存放 Web 管理後台（~1MB）
  - 小智 AI 多語言資源包（.p3 檔案）
  - NVS 設定分區
  - 預留升級空間
- 無需擔心固件體積，多 Agent AI 可以完整裝入

### 8.5 DVP 攝影機輸入引腳約束

- D0-D7 及 VSYNC/HREF/PCLK 均為輸入引腳，由攝影機傳感器驅動
- 驅動程式開發時必須確保這些引腳僅設定為 INPUT 模式
- I2S 音訊引腳（38,39,40,47,48）可設定為輸出模式（ESP32-S3 支援）
