## Layout / 内容结构

Each language folder contains 14 documents: 11 chapters (Ch01–Ch11) plus Quick Start, Serial Protocol Manual and Hardware Spec, and a code-download page.

每个语言目录包含 14 篇文档：11 章教程（Ch01–Ch11）+ 快速开始、串口协议手册、硬件规格书，以及代码下载页。

`files/` holds the shared firmware source archives and tools. / `files/` 目录为各语言共享的固件源码压缩包与工具。
